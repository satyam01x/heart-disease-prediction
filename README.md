# Heart Disease Prediction ❤️

This project uses Machine Learning (Logistic Regression) to predict heart disease.

## Features

* Data preprocessing
* Train-test split
* Feature scaling
* Logistic Regression model
* Accuracy evaluation

## Accuracy

~79%

## Technologies Used

* Python
* Pandas
* Scikit-learn

## How to Run

1. Install dependencies
2. Run Jupyter Notebook
